# Color Me Lucky — Launch Guide

## Starting a game

Open the game’s **Lobby** route on each player device. Each person should choose only their own seat, then select **Enable Sound** if they want audible answer feedback. A seat can be active in only one browser at a time; a browser refresh reconnects using its saved player claim.

The room stays in the lobby until the host locks the order. Players can open **Play** after choosing a name, but answer controls remain locked unless they are the active hot-seat player. During a live round, an answer is accepted only once and only if received by the server before the 60-second deadline.

## Host flow

The administrator signs in and opens the **Host** route. Select **Start demo** for the deliberate all-player answer test, or select **Lock order** and then **Start hot seat** for the standard game. The host may advance the active player, pause the room, start a tiebreaker, review the final board, or reset the room for a fresh rehearsal.

## Tiebreakers and reserves

When a player exhausts the 13 primary questions, the server automatically rotates through that player’s five-question reserve bank. Reserve questions are never used for tiebreakers. The dedicated five-question tiebreaker bank is available only after a points tie; eligible players have one attempt per question, and the first correct response **received by the server** wins.

## Five-minute preflight

Before game time, have each player choose a seat and enable sound if desired. Confirm that the host can start and pause a round, that only the hot-seat player can answer, that a refresh restores the selected seat, and that a sample tiebreaker credits the first correct server receipt.
