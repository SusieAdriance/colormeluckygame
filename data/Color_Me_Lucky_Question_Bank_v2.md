# Color Me Lucky — Question Bank Refresh (v2)

**Purpose:** Full replacement question set for the existing "Color Me Lucky" game build. Everything below is brand new content, structured to drop into the existing spec (same rules, host panel, sound effects, and mechanics from v1 do not need to change, only the question data).

**What's new in v2:**
- Two new categories added: **Food & Cuisine** and **Science & Nature**, alongside the original General Knowledge, Pop Culture, Geography, Brain Teasers, and Culture (Florida / Puerto Rico / Philippines).
- Team Personalized questions refreshed, including a nod to the accounting team's infamous 0-for-everything run on the Jeopardy-style game night.
- Same totals as v1: 65 primary questions (13 per player, 5 players), 25 reserve questions, 3 unscored demo questions, 5 tiebreakers. 98 total.
- Color traps distributed the same way: roughly 2 to 3 per player pool, plus a dedicated Color Trap Specials block in the reserve bank.

---

## Mechanics Reminder (unchanged from v1)

- Each question has 4 answer choices on 4 colored buttons: red, blue, green, yellow.
- Only 1 answer is correct.
- Correct answer position is randomized across colors.
- **Color trap** questions: the correct answer names a color, and that answer is deliberately placed on a *different* colored button than the color it names.
- Questions are pre-assigned per player, 13 each, no repeats across the game.
