# Color Me Lucky, Question Bank v3

**Purpose:** Third full question bank for the existing Color Me Lucky build. New content throughout, with a brand new Disney Characters category (classic animated films emphasis: Mickey, villains, princesses) added alongside the usual mix.

**What's new in v3:**
- New category: Disney Characters, focused on classic animated Disney films.
- Same category lineup as before otherwise: General Knowledge, Pop Culture, Geography, Brain Teasers, Culture (Florida, Puerto Rico, Philippines), Food and Cuisine, Science and Nature, Team Personalized.
- Same totals as the live build: 65 primary questions (13 per player, 5 players), 30 reserve questions (25 standard plus 5 Color Trap Specials, same split the build script expects), 3 unscored demo questions, 5 tiebreakers, 103 total.
- Team personalized questions reuse the same facts as before, per your direction: Francisco's Puerto Rico base, Roo the Shorkie Poo, the team's Florida/Puerto Rico/Philippines footprint, and the accounting team's legendary Jeopardy style trivia loss.
- 10 color traps total: 5 spread across the player pools, 5 in the Color Trap Specials block in reserve.
- Formatting note for whoever runs the build script: the Reserve Bank and Tiebreaker section headers below must stay exactly as written, including the dash, since the parser matches them as literal text.

---

## Mechanics Reminder (unchanged)

- Each question has 4 answer choices on 4 colored buttons: red, blue, green, yellow.
- Only 1 answer is correct.
- Correct answer position is randomized across colors.
- Color trap questions: the correct answer names a color, and that answer sits on a button of a different color than the one it names.

## Handoff Notes

- This replaces the question data only. Game rules, host panel, sound effects, scoring logic, and UI stay as-is.
- Total inventory: 103 questions (3 demo, 65 primary across 5 players, 30 reserve, 5 tiebreaker). The reserve section is labeled "25 Questions" in its header, but the standard 25 plus the 5 Color Trap Specials are both read from that same section, matching how the build script already expects the file to be structured.
- Color traps: 10 total, 5 spread through the player pools, 5 in the dedicated specials block in reserve.
- Disney Characters is tagged alongside the existing categories in the same filtering system.
- Team personalized questions intentionally reuse the same facts from the prior bank, since the team already knows them and gets a kick out of the callbacks.

### How to load this into the live game

The game reads its questions from `shared/gameData.ts`, which is generated from a markdown file like this one by `scripts/build-game-data.mjs`. To load v3:

1. Add this file to the repo, for example at `data/Color_Me_Lucky_Question_Bank_v3.md`.
2. In `scripts/build-game-data.mjs`, update the `sourcePath` constant to point at this file instead of the v2 one, and update the version string from `"v2"` to `"v3"` in the two spots it appears in the generated output header.
3. Run the script (`node scripts/build-game-data.mjs`), which regenerates `shared/gameData.ts` in place.
4. Commit and push. Railway redeploys automatically from the GitHub connection, no other config needed.

The fastest way to get this done is to hand this file straight to Manus along with those four steps, since it already built and ran this exact pipeline for v2.
